# R.O.B. Vision 0.2.0

This release brings Buddy's console connection, controller assignments, and Matrix cues into the shared Controller Router service. Gyromite and Stack-Up select R.O.B. Vision automatically when their registered games start; the browser remains the place to watch and guide Buddy.

## What's new

- Pair a console once through Controller Router's secure Setup. R.O.B. Vision receives its own access after pairing, including when it is installed after VirtualGlove.
- Use **Apps** on the controller to open R.O.B. Vision or VirtualGlove. The shared Matrix displays the selected game's cues and returns to its idle animation after play.
- Use **Players and Systems** to inspect controller assignments and choose which Libretro systems use Router. Buddy's games need Router enabled for NES.
- Play on Recalbox alongside RetroPie and Batocera. The console installer includes the corresponding frame wrappers and supports the same install-or-upgrade command.
- Find clearer Setup, Help, pairing, and troubleshooting instructions. Runtime routing leaves saved RetroArch configuration alone.

The release includes the User Guide, Installation & Setup, Game Manual, technical guides, Matrix guide, quick reference, and three *Buddy & the Big Wide Window* episodes as PDFs. It includes no ROMs. See [Installation & Setup](INSTALLATION_AND_SETUP.md) for the current commands and [Game Manual](GAME_MANUAL.md) for play.
