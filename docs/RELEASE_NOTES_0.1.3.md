# R.O.B. Vision 0.1.3

This documentation release aligns the current guides, built-in Help, and four printable manuals with the shipped RetroPie and Batocera integrations. Console status, game identification, Gyromite Controller 2 return, and troubleshooting now describe either paired console. The Stack-Up Test-mode and verification notes describe the implemented automatic red-light indication. Historical camera reports remain clearly labeled as research.

The controller, emulator integrations, installer behavior, and supported hardware are unchanged from 0.1.2. Supported systems remain UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64. The release package contains no ROMs. See the [0.1.0 validation report](RELEASE_VALIDATION_0.1.0.md) for live device evidence.
