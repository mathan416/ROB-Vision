# R.O.B. Vision 0.1.2

This documentation patch removes repeated statements about absent robot hardware from Help, the player guides, and project descriptions. The Help sidebar now gives a play tip, and the FAQ concentrates on actual setup and gameplay questions.

The controller, emulator integrations, and supported hardware are the same as in 0.1.1. The four manuals and built-in Help are rebuilt from the corrected text. The one-command installer and source package remain SHA-256 checked.

Supported systems: UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64. See the [0.1.0 release notes](RELEASE_NOTES_0.1.0.md) for gameplay details and the [validation report](RELEASE_VALIDATION_0.1.0.md) for live device evidence. The release contains no ROMs.
