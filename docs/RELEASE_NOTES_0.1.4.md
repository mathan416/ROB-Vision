# R.O.B. Vision 0.1.4

The UNO Q installer now prints working Mission and Setup addresses using the device's `.local` hostname and each active LAN IPv4 address. Help and installation guides show both address forms and explain that mDNS comes from the UNO Q's hostname and Avahi service, not from a separate R.O.B. Vision registration. This also makes the first-run instructions usable on a UNO Q named something other than `arduiain`.

The controller, emulator integrations, and supported hardware are unchanged from 0.1.3. Supported systems remain UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64. The release contains no ROMs.
