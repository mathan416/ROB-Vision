# R.O.B. Vision Setup

Open `http://arduiain.local/dashboard/setup.html`. Console Link lists every saved RetroPie and Batocera console separately, with its address and live status. Setup has four checks:

On Batocera 43.1 x86_64, first install with `python3 scripts/install_batocera.py --controller arduiain.local` from a staged checkout. For first pairing run `python3 /userdata/system/rob-vision/tools/retropie_pair.py --platform batocera` and enter its code and fingerprint on Setup. The exact Gyromite and Stack-Up ROMs automatically use the R.O.B. Vision FCEUmm wrapper; Nestopia is an optional per-ROM choice. [Batocera installation details](../deploy/batocera/README.md).

1. **Pair the console.** Install the receiver and launch hooks first. On RetroPie run `python3 /home/pi/rob-vision/tools/retropie_pair.py`. For five minutes it shows a six-digit code and SHA-256 fingerprint. Enter its hostname, code, and fingerprint on Setup, then select **Pair Console**. The UNO Q verifies the certificate fingerprint before sending a unique console credential over the encrypted pairing connection. Repeat for another console using **Pair Another Console**. Each appears under **Paired Consoles**; **Check Link** counts recent authenticated polls, and an individual row goes offline after three seconds without one. Pairing does not install the receiver or emulator choices.
2. **Check game frames.** On RetroPie, select `lr-robvision-fceumm` or `lr-robvision-nestopia`. On Batocera, launch an exact registered ROM; its R.O.B. Vision FCEUmm wrapper is selected automatically. Setup should show **GAME FRAMES LINKED**. The wrapper forwards each rendered NES light cell to the local receiver, which sends complete commands to the UNO Q. The plain `lr-fceumm` and `lr-nestopia` entries play without this link.
3. **Check Test mode.** Launch the game through its R.O.B. Vision emulator choice and enter Test mode. Gyromite's sustained green field or Stack-Up's alternating green/white frames make R.O.B.'s red head light blink automatically on Mission and Setup. A separately decoded ready-light command makes it glow steadily. Neither moves arms or game pieces. **Preview Red Light** only demonstrates the animation. If the light stays off, check **GAME FRAMES LINKED** and confirm the game is in Test mode. In Stack-Up, press Select at the ROBOT BLOCK artwork to show the mode list, choose Test, then press Start.
4. **Try the controls.** For Gyromite, **Lower Red** and **Lower Blue** press matching virtual pads immediately; press again to release or choose **Release Both**. Each hold expires after 60 seconds. For Stack-Up, **Left, Right, Up, Down, Open, Close** send one command to the virtual model. Stack-Up has no Gyromite-style Controller 2 return path. Watch Mission's Live Model and Game Table for movement.

A `file://` Setup page is only an offline preview. Use the UNO Q URL for live status. Mission keeps Fast Gates and the Game Table next to Pose Preview and System Vitals.

To forget a console, select **Remove** in its row and then **Confirm Remove**. The UNO Q immediately revokes that console's credential; any other paired console remains connected. If the removed console was playing, its game session is cleared. The removed console retains its old local credential, but it can no longer authenticate; run its pairing command again to reconnect it. Only one console can be the active game source at a time.
