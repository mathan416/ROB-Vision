# R.O.B. Vision parts plan

The UNO Q hosts the controller and LED status display. A browser shows Buddy and his game pieces.

| Item | Current status |
| --- | --- |
| Arduino UNO Q | In use for App Lab controller, HTTP panel, virtual state, and LED matrix sketch. |
| RetroPie or supported Batocera game host | Runs Gyromite or Stack-Up, sends game-frame commands, and receives Gyromite's virtual Controller 2 state. |
| UNO Q power and enclosure | Use adequate supply and ventilation; an enclosure is optional. |
| Wi-Fi or Ethernet adapter | Current setup uses an Ethernet adapter on a USB hub; Wi-Fi uses the same app protocol. |
| Laptop, tablet, or phone | Main browser display for R.O.B. and game accessories. |
