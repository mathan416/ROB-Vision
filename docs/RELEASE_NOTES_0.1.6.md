# R.O.B. Vision 0.1.6

This release completes the documentation set and updates the built-in Help. The Game Manual now shows both Gyromite and Stack-Up game tables, the illustrated Installation & Setup guide covers the two one-command installs, and Buddy's full-page comic is available alongside the guides.

The Technical Reference describes the current emulator frame link and virtual model. Technical Test Results records the earlier live optical and Kiyo Pro row experiments, frame-link tests, and their limits. Engineering Journey tells how the project moved from a camera to FCEUmm and Nestopia frame hooks. Help links to all nine PDFs on the UNO Q.

The installer, game controls, and supported devices are unchanged from 0.1.5: UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64. No ROMs are bundled.
