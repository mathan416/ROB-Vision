# R.O.B. Vision 0.1.5

This documentation release combines the overlapping network architecture and parts pages with their primary technical guides. The documentation index and Technical Reference now have one path to network behavior, console identity, required devices, and UNO Q setup. The four printable manuals and built-in Help are refreshed from the current sources.

The installer still prints device-specific `.local` and LAN IP addresses, as introduced in 0.1.4. Controller and emulator behavior and supported hardware are unchanged. Supported systems remain UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64. No ROMs are bundled.
