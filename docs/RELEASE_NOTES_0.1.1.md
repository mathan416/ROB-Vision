# R.O.B. Vision 0.1.1

This documentation update keeps the 0.1.0 game controller, emulator integrations, and supported hardware.

- Help now keeps setup, play, and troubleshooting instructions together. Buddy's story has its own optional section, told as fiction instead of project commentary.
- The User Guide chapter tells Buddy's story without design or rights notes inside the narrative. The README and guide opening point to that chapter without describing character planning.
- The four PDF manuals have current cover labels and platform names. The technical reference opening describes the runtime; dated test evidence stays in the 0.1.0 validation report.
- Installation instructions and release assets use the 0.1.1 tag. The one-command installer still checks its source package with SHA-256 before making changes.

UNO Q App Lab, standard RetroPie with the `pi` account, and Batocera 43.1 x86_64 remain the supported systems. See the [0.1.0 release notes](RELEASE_NOTES_0.1.0.md) for gameplay and platform details, and the [validation report](RELEASE_VALIDATION_0.1.0.md) for the live checks. The release contains no ROMs.
