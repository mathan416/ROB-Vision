# RetroPie connection

The dedicated `retropie.local` test machine runs the launch/end scripts in this folder and `rob-vision-controller2.service`. The scripts notify the UNO Q at `http://arduiain.local` using a private token file at `/home/pi/.config/rob-vision/token`. They allow game launch to continue if the UNO Q is unavailable. The service polls the UNO Q's current Gyromite pad state, creates a Linux virtual joystick through `/dev/uinput`, and releases both buttons if the UNO Q cannot be read or the Gyromite emulator process is absent. No ROM or token is stored in this repository.

The current NES-specific RetroArch configuration forces Player 2 to Gamepad (`input_libretro_device_p2 = "1"`) and assigns joystick index 1 to Controller 2. The receiver emits red as Linux button 0 and blue as button 1. In a real Game A test, button 0 initially moved the visible blue gate, so the RetroArch profile and NES config now map button 1 to A and button 0 to B. After a restart, an isolated blue hold moved the blue gate and release returned it. The player subsequently confirmed that both red and blue controls work in Game A. `--swap-buttons` on the receiver is an alternative way to reverse the two colors, but is not enabled on this machine. RetroArch reads the NES configuration when a game starts, so restart Gyromite after installing or changing its mapping.

The service is enabled through systemd and should be running before the game launches. Its status is available with `systemctl status rob-vision-controller2.service`; the virtual pad should appear as `/dev/input/js1` while the existing player's controller is `/dev/input/js0`. The UNO Q app must be running in App Lab. Its camera still needs a real capture device and optical timing calibration before the flashes can drive R.O.B. automatically.

On this RetroPie, the existing Sony controller profile had Start assigned as both game Start and emulator Exit. It prevented Gyromite from starting. The test-machine profile now reserves Start (button 8) for the game, with Select (button 9) as the hotkey modifier and right-stick click (button 12) assigned to Exit. Start has been observed entering Gyromite Test mode. The controller exit combination has not yet been confirmed; the connected keyboard's Escape key is configured to exit RetroArch. The original profile is backed up beside it as `Sony Computer Entertainment Wireless Controller.cfg.before-rob-vision`. Restart the game after any mapping change.

On another RetroPie machine, inspect existing runcommand scripts and merge the calls rather than replacing other projects' hooks. The test machine had no custom scripts before installation. Back up the NES RetroArch configuration before adding the four Controller 2 lines above its `#include` line. Protect the UNO Q token file with owner-only permissions. The copies on the test machine are in `/home/pi/rob-vision/`; the NES config backup is `/opt/retropie/configs/nes/retroarch.cfg.before-rob-vision`.
