VERSION 0.1.6 / TWO DEVICES / ONE PAIRING

LET'S GET
BUDDY MOVING.

Install once on your UNO Q, once on your console, and pair them in Setup. The browser becomes Buddy's stage.

BEFORE YOU BEGIN

WHAT YOU NEED.

Put both devices on the same trusted local network. Use a laptop, tablet, or phone on that network to open the UNO Q dashboard.

01

ARDUINO UNO Q

App Lab installed, with terminal access as arduino. The UNO Q owns Buddy, the pieces, the browser panel, and the LED matrix.

02

A GAME CONSOLE

Standard RetroPie with the pi account, or Batocera 43.1 x86_64 with the root account. Other Batocera boards and versions are reported as unsupported.

03

YOUR GAMES

Your own legally obtained Gyromite or Stack-Up NES ROM. R.O.B. Vision does not include ROMs. The supported game files use the registered World filenames.

STEP ONE / THE ROBOT'S HOME

INSTALL ON UNO Q.

Run this command in the UNO Q terminal as arduino. The installer verifies the release package, installs the App Lab app, and starts Buddy.

UNO Q / VERSION 0.1.6
curl -fsSL https://github.com/mathan416/ROB-Vision/releases/latest/download/install.sh | sh -s -- uno-q

OPEN THE PRINTED LINK

When installation finishes, it prints Mission and Setup links using the UNO Q's .local name and available LAN IP addresses. Use either address in your browser. No USB browser connection is needed.

THE LITTLE SCREEN

The install includes Buddy's UNO Q matrix sketch. The display shows startup, ready eyes, game selection, pairing, and Test cues while the full animation appears in your browser.

STEP TWO / THE GAME HOST

INSTALL ON YOUR CONSOLE.

Use the same console command on RetroPie or Batocera. Replace your-uno-q.local with the hostname or LAN IP printed by the UNO Q installer.

RetroPie first: exit any running game and EmulationStation to its shell before installing. Restarting its virtual controller while the menu is open can crash the input manager. On Batocera, the installer pauses and resumes the menu while it updates the controller.
RETROPIE OR BATOCERA / VERSION 0.1.6
curl -fsSL https://github.com/mathan416/ROB-Vision/releases/latest/download/install.sh | sh -s -- console your-uno-q.local

Run it as pi on RetroPie or root on Batocera. It detects the platform, installs the frame integration and receiver, and prepares Gyromite's virtual Controller 2. Repeating the command upgrades an existing installation while retaining its pairing.

STEP THREE / SAY HELLO

PAIR THE CONSOLE.

A first installation prints a six-digit code and certificate fingerprint, then waits for you to connect from the UNO Q's Setup page.

01

KEEP THE CONSOLE TERMINAL OPEN

The pairing window lasts five minutes. Keep its code and fingerprint visible; do not enter a password or private key on the web page.

02

OPEN SETUP ON THE UNO Q

In Console Link, enter the console address, six-digit code, and fingerprint exactly as printed. Choose Pair Console.

03

CHECK THE LINK

Wait for Pairing complete in the console terminal, then choose Check Link in Setup. You can pair more than one console; one game session is active at a time.

STEP FOUR / PLAY

GIVE BUDDY
A MISSION.

Launch a registered game and leave Mission open on your laptop, phone, or tablet to watch him respond.

ON RETROPIE

Choose lr-robvision-fceumm or lr-robvision-nestopia for the registered Gyromite or Stack-Up ROM. A regular NES core plays the game without the automatic frame link.

ON BATOCERA

Launch a registered ROM. The installer selects the R.O.B. Vision FCEUmm wrapper; a supported Nestopia per-game choice can be retained.

Mission and Setup should show the selected game and GAME FRAMES LINKED. In Test mode, Buddy's red light blinks. In Gyromite, try the separate Fast Gate buttons; in Stack-Up Direct mode, move Hector onto a command key.

HELP WHEN YOU NEED IT

READY FOR THE
NEXT MOVE.

Rerun the same installation command to upgrade or repair. Pairing is retained. To reconnect a console you removed in Setup, append --pair to its console command.

NO GAME SELECTED?

Check that the ROM filename matches the registered game and launch it again. Online console status alone does not mean a game is running.

NO MOVEMENT?

Look for GAME FRAMES LINKED. Confirm the R.O.B. Vision core choice and read Mission's Activity Feed for decoded or blocked commands.
