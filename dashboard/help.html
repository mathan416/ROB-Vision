01 / THE BASICS2 MIN READ

Start here

R.O.B. Vision turns game commands into a lively virtual robot. The UNO Q is his controller, your browser is his stage, and RetroPie or Batocera runs the NES game.

01

Start a game

Launch a registered Gyromite or Stack-Up game on your paired console. Controller Router selects R.O.B. Vision automatically; no browser needs to be open for Buddy to play. When the game ends, Router releases the controls and returns to its neutral display.

02

Watch Buddy or run a demo

Open the UNO Q address on a laptop, tablet, or phone to watch Buddy. When the console is idle, choose a game on Mission and select Run Demo Sequence to see the pieces animate.

03

Check the connection

On Setup, check the console link and game controls. The game-frame link moves Buddy from rendered NES frames. Finish a live game before changing controller apps manually. The UNO Q address opens the sole installed app or shows a chooser when both are installed. Apps appears only with both products and returns to that chooser; it does not start or stop the services.

02 / GET CONNECTEDSETUP

Set up the console link

Install and pair a console

  1. On RetroPie, exit the game and EmulationStation before installing.
  2. Install R.O.B. Vision on the UNO Q using the Installation & Setup Guide. Open the Setup link printed by the installer, or choose R.O.B. Vision at the UNO Q address and then open Setup.
  3. Run the console installer on RetroPie or Batocera with your UNO Q address. Leave its terminal open; it will show a pairing code and fingerprint.
  4. In Console Link, enter the console’s address, code, and fingerprint. Choose Pair Console.
  5. When the console says Pairing complete, choose Check Link.

Pairing starts the receiver and Controller Router, with Buddy assigned to Player 2. Existing physical-controller assignments stay in place. To add another console, choose Pair Another Console. A console can use one UNO Q at a time.

To disconnect a console, choose Remove, then Confirm Remove. To reconnect it later, rerun the console installer with --pair.

GO TO CONSOLE LINK ↗

Assign game controllers

Open Controller Router’s Setup at the UNO Q address, select the paired console, and choose Controller Router or My existing setup for each system under Systems. Exit the game before saving. Fresh installs enable NES only; upgrades retain your selections. Buddy’s games and VirtualGlove require Controller Router enabled for NES.

Controller Router assigns physical gamepads and Buddy to RetroArch players. Buddy stays on Player 2; your physical Player 1 pad controls Hector and game menus.

Choose Controllers beside a paired console to review its assignments. Open the Controller Router guide below for testing, changes, and recovery.

OPEN CONTROLLER ROUTER ↗

Register your ROM filenames

  1. In Console Link, choose Edit ROMs beside the console you want to change.
  2. Under games, add the ROM’s exact filename, including its extension. Set its value to gyromite or stack_up.
  3. Choose Validate. Fix any errors it reports.
  4. Exit the game if it is running, then choose Save to Console. The new filename works on the next launch.

Each console keeps its own registry through upgrades. You can download a backup or restore the previous save from this editor.

GO TO GAME REGISTRY ↗

Link game frames

  1. On RetroPie, choose lr-robvision-fceumm or lr-robvision-nestopia. On Batocera, launch the registered ROM; the installer selects a R.O.B. Vision core and preserves an existing supported Nestopia choice.
  2. Setup and Mission should show GAME FRAMES LINKED.
  3. Enter Direct mode and send a game command. Watch R.O.B. move on Mission.
  4. Enter Test mode and watch R.O.B.’s red light blink automatically on Mission or Setup.

The console sends complete game commands from the rendered frames to the UNO Q.

PLAYER INPUTCONTROLLER ROUTER

Put each controller on the right player

Controller Router carries physical gamepads and Buddy into RetroArch through named Player 1–4 gamepads. Your original pads still navigate EmulationStation. Buddy is fixed on Player 2 for Gyromite's gates; a physical pad usually belongs on Player 1 for Hector, game Start, and menu or exit controls.

Review and test

  1. Open the live Setup page and choose Controllers beside the console you are using.
  2. Read each controller name and player assignment. A console saves its own list; another console may be different.
  3. Choose Test Inputs and press a button or direction on each pad during the five-second test. No activity means nothing was detected during that test; try again while pressing it.
  4. If a pad is on the wrong player, close the game, change its assignment, choose Save Assignments, and relaunch.

What the choices mean

Player 1: the pad for Hector and ordinary game controls. Player 2: Buddy's virtual buttons for Gyromite's red and blue gates. Another physical pad can share a player if you choose.

Connected means a saved pad is present; Unavailable means reconnect it or assign its replacement. Mapping updated means EmulationStation supplied a newer valid button map for the same pad; its player stays the same.

Reload discards unsaved page choices. Restore Previous returns to the last saved assignment when a backup exists. Buddy's Player 2 assignment is fixed.

Wrong pad?If your usual gamepad stops controlling the game, try another connected pad. The one in your hands may be Player 2 while another is Player 1. Check the names and slots in Setup before changing RetroArch settings.

RetroArch 1.19.1 uses temporary routing settings for each launch. Supported newer builds use strict named-device reservations. Neither path rewrites your saved RetroArch configuration during play.

Router handles player input; it does not identify ROM filenames or carry the game's light commands. The game-frame link and the console link have their own indicators on Setup. See the User Guide for a full walkthrough and recovery steps.

03 / PLAY A GAMEGYROMITE

Move the red and blue gates

Gyromite has two virtual gyros, holders, a spinner, and two colored pads. Buddy starts at level 6. Two Down commands move through level 4 to level 2, our working height for picking up or placing a gyro at any station. Raise a carried gyro once to level 4 before turning; level 6 gives more clearance. A gyro presses a button while resting on its colored pad. The original manual's positions 1–5 name slots around R.O.B.'s base, not arm heights. The stations look higher or lower because of the table's perspective. A spinning gyro can keep a gate lowered while Buddy moves elsewhere; he can also hold an unspun gyro on a pad to operate one gate.

Fast Gates

During live Gyromite, use Fast Gates. Select Lower Blue or Lower Red for an immediate press; select it again to release. Release Both raises both. Every hold ends automatically after 60 seconds.

On Mission, 2 toggles blue, 1 toggles red, and 0 releases both. Shortcuts work while Gyromite is active and you are not typing in a field.

Buddy’s hands must be empty, the matching gyro must be on its holder, and the target pad must be free. Return the pieces with regular controls or choose Home to reset the gyros.

What the game receives

The UNO Q's virtual pad state travels to the active console's Controller 2. Watch the game screen to confirm Hector's position and the gate's response.

On game exit, lost link, or stale receiver data, both virtual buttons release.

04 / PLAY A GAMESTACK-UP

Arrange the five blocks

R.O.B. Vision shows five colored blocks and five trays. The five blocks start on Tray 3, from top to bottom: red, white, blue, yellow, green. Use Left, Right, Up, Down, Open, Close to move R.O.B. one step at a time. Each block occupies one hand level. When his open hands reach a block, it glows and the Game Piece card shows the blocks he can pick up. Closing his hands carries that block and every block above it as a group; the card then shows the carried stack.

Try a transfer

At the ROBOT BLOCK screen, press Select to open Stack-Up’s mode list; choose Test and press Start. The Test signal appears over the ROBOT BLOCK artwork. R.O.B.’s red light blinks automatically when the linked Test signal arrives. In Direct mode, jump Hector onto a command key and watch R.O.B. act on Mission. The six manual commands remain available for checks. Raise his hands above a stack before moving sideways past it. Open hands may lower around the current stack to pick a lower block; closed hands cannot. A blocked move leaves Buddy and every block in place. Home restores the initial stack.

Current game limits

The game sends movement commands without a block color, destination, target pattern, or score. Compare the virtual arrangement with the target on the game screen. Bingo's different starting arrangements are not modeled. Stack-Up does not use Gyromite's gate-button return path.

Connected

GYROMITE / CONNECTED means this browser can reach the UNO Q with Gyromite selected. Console status is shown separately.

Game Selected

Gyromite or Stack-Up was chosen manually or identified by its console ROM filename.

Game Frames Linked

The console is sending the selected game's rendered NES frames through the R.O.B. Vision wrapper.

07 / GET UNSTUCKTROUBLESHOOTING

Fix a problem

The console is online, but no game is selected

A console can be online while idle. Launch a registered Gyromite or Stack-Up ROM. Use the UNO Q address for live status, then refresh Mission.

R.O.B. does not move from game flashes

Confirm the game is selected and the console is online. Mission should show GAME FRAMES LINKED. If it does not, select lr-robvision-fceumm or lr-robvision-nestopia in RetroPie, or confirm the registered ROM uses its R.O.B. Vision wrapper in Batocera, then restart the game. Check the Activity Feed for decoded or blocked commands.

The blue or red gate stays still

Use an isolated Fast Gate test in live Gyromite. Confirm the console is online and Game A is running. Watch the matching gate while the button is held. Use Release Both when done.

A wireless controller falls asleep or wakes during a game

Router resolves the named merged controllers before each game starts. Physical pads reconnect to their saved players after sleeping or waking; the merged controllers stay connected. If Router itself restarts or its output devices disappear, exit the game, wait for Router to become ready, then relaunch. Changing a player assignment also takes effect on the next launch.

Stack-Up rejects a move

Check Buddy's tray, height, and grip. Raise his hands to the level named in the Activity Feed before moving sideways into a stacked tray. Open his hands before lowering around blocks on the current tray. A blocked command changes no blocks or position; send another command to continue.

Demo button is unavailable

Exit the running game first. Demo mode works when the console is paired but idle. Choose Home to reset a sequence.

08 / GOOD TO KNOWFAQ

Common questions

Can I use a phone or iPad?

Yes. Open the UNO Q dashboard address in a browser on the same trusted network. The live state belongs to the UNO Q, so reloading the page does not reset the game.

Why are there R.O.B. Vision versions of FCEUmm and Nestopia?

lr-robvision-fceumm and lr-robvision-nestopia are RetroPie launch choices. Each uses the original emulator through a small wrapper that sends game flashes to R.O.B. Vision. The standard emulator choices play without the automatic frame link. On supported Batocera, the installer selects the R.O.B. Vision FCEUmm wrapper for registered ROMs; Nestopia is available as a per-game choice.

How does R.O.B. read the game?

The console reads the game’s light signals from rendered NES frames and sends complete commands to the UNO Q.

Does the red Test light mean R.O.B. is moving?

No. A blinking red light acknowledges the game’s Test-mode signal; brief steady red acknowledges a ready-light command. Movement needs a separate complete optical command.

Why does a gyro stop spinning?

Each virtual gyro has an illustrative 55-second spin lifetime. When it tips or leaves a pad, that virtual gate releases.

Can R.O.B. see Hector or score Stack-Up?

Use the game screen to check Hector’s position, target stack, score, and victory. The frame link reports movement commands.
