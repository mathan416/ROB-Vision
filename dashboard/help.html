01 / THE BASICS2 MIN READ

Start here

R.O.B. Vision turns game commands into a lively virtual robot. The UNO Q is his controller, your browser is his stage, and RetroPie or Batocera runs the NES game.

01

Open the live panel

Start R.O.B. Vision in UNO Q App Lab, then open the installer’s Mission link on your laptop, tablet, or phone. It uses this UNO Q’s .local name or LAN IP address. Stop another App Lab app first if one is running.

02

Run a demo

On Mission, choose Gyromite or Stack-Up and select Run Demo Sequence. R.O.B. and the pieces animate without a running game. Demo mode is available while the console is paired and idle.

03

Connect the game

On Setup, check the console link and game controls. Launching a supported game on RetroPie or Batocera selects its live scene automatically. The game-frame link moves R.O.B. from rendered NES frames.

Looking at a local file?A page opened with file:// is only the offline preview. It cannot show the current console game. Open the Mission link printed by the UNO Q installer, using its .local hostname or LAN IP address, for live play.
02 / GET CONNECTEDSETUP

Set up the console link

Install and pair a console

  1. On the UNO Q, run the one-command installer shown in the Installation & Setup Guide. It prints device-specific Mission and Setup links using both the .local hostname and available LAN IP addresses.
  2. Run the console's one-command installer on RetroPie or Batocera with your UNO Q hostname. It detects the platform and prints a code and fingerprint.
  3. Enter the console’s .local hostname or LAN IP address, six-digit code, and fingerprint on Setup; choose Pair Console.
  4. Keep the console command open until it says Pairing complete, then choose Check Link.

Exit games and EmulationStation on RetroPie before installing; restarting its virtual joystick while EmulationStation is open can crash the input manager. On Batocera, the installer pauses and resumes the menu while updating its virtual joystick. Pairing starts the receiver and sets Gyromite's virtual Controller 2 automatically. On Batocera, the installer checks that an NES core and a usable frame wrapper are available before changing files. Console Link lists every paired console separately. A console uses one UNO Q at a time; pairing it to another updates its receiver address. The previous UNO Q keeps a saved row marked Receiver Waiting until you remove it. That status means no recent check-in, even if the console is powered on and reachable by name. Edit ROMs opens that console’s own game registry. Remove revokes one credential; to reconnect it, run the console command again with --pair at the end.

GO TO CONSOLE LINK ↗

Register your ROM filenames

On Setup, choose Edit ROMs beside your paired console to open its Game Registry, then add each exact NES filename under games with the value gyromite or stack_up. Keep the file extension. Select Validate, then Save to Console. Exit any running game before saving; the new mapping applies on the next launch. The editor can download a backup or restore the previous save. Each console has its own registry, and installer upgrades retain your edits.

GO TO GAME REGISTRY ↗

Link game frames

  1. On RetroPie, choose lr-robvision-fceumm or lr-robvision-nestopia. On Batocera, launch the registered ROM; the installer selects a R.O.B. Vision core and preserves an existing supported Nestopia choice.
  2. Setup and Mission should show GAME FRAMES LINKED.
  3. Enter Direct mode and send a game command. Watch R.O.B. move on Mission.
  4. Enter Test mode and watch R.O.B.’s red light blink automatically on Mission or Setup.

The console sends complete game commands from the rendered frames to the UNO Q.

03 / PLAY A GAMEGYROMITE

Move the red and blue gates

Gyromite has two virtual gyros, holders, a spinner, and two colored pads. Buddy starts at level 6. Two Down commands move through level 4 to level 2, our working height for picking up or placing a gyro at any station. Raise a carried gyro once to level 4 before turning; level 6 gives more clearance. A gyro presses a button while resting on its colored pad. The original manual's positions 1–5 name slots around R.O.B.'s base, not arm heights. The stations look higher or lower because of the table's perspective. A spinning gyro can keep a gate lowered while Buddy moves elsewhere; he can also hold an unspun gyro on a pad to operate one gate.

Fast Gates

During live Gyromite, use Fast Gates. Select Lower Blue or Lower Red for an immediate press; select it again to release. Release Both raises both. Every hold ends automatically after 60 seconds.

Keyboard shortcuts: 2 blue, 1 red, 0 release both. If you moved a gyro with regular controls, choose Home before Fast Gates.

What the game receives

The UNO Q's virtual pad state travels to the active console's Controller 2. Watch the game screen to confirm Hector's position and the gate's response.

On game exit, lost link, or stale receiver data, both virtual buttons release.

04 / PLAY A GAMESTACK-UP

Arrange the five blocks

R.O.B. Vision shows five colored blocks and five trays. The five blocks start on Tray 3, from top to bottom: red, white, blue, yellow, green. Use Left, Right, Up, Down, Open, Close to move R.O.B. one step at a time. Each block occupies one hand level. When his open hands reach a block, it glows and the Game Piece card shows the blocks he can pick up. Closing his hands carries that block and every block above it as a group; the card then shows the carried stack.

Try a transfer

At the ROBOT BLOCK screen, press Select to open Stack-Up’s mode list; choose Test and press Start. The Test signal appears over the ROBOT BLOCK artwork. R.O.B.’s red light blinks automatically when the linked Test signal arrives. In Direct mode, jump Hector onto a command key and watch R.O.B. act on Mission. The six manual commands remain available for checks. Watch the Live Model and Game Table. An invalid pickup or placement is rejected without moving any block. Home restores the initial stack.

Current game limits

The game sends movement commands without a block color, destination, target pattern, or score. Compare the virtual arrangement with the target on the game screen. Bingo's different starting arrangements are not modeled. Stack-Up does not use Gyromite's gate-button return path.

06 / READ THE PANELSTATUS & SIGNALS

What the indicators mean

Connected

GYROMITE / CONNECTED means this browser can reach the UNO Q with Gyromite selected. Console status is shown separately.

Game Selected

Gyromite or Stack-Up was chosen manually or identified by its console ROM filename.

Game Frames Linked

The console is sending the selected game's rendered NES frames through the R.O.B. Vision wrapper.

Test Light

Blinking means the game-frame link detected Test mode. Brief steady red means a ready-light command was decoded; the game face returns automatically. Neither moves R.O.B.

07 / GET UNSTUCKTROUBLESHOOTING

Fix a problem

The console is online, but no game is selected

A console can be online while idle. Launch a registered Gyromite or Stack-Up ROM. Use the UNO Q address for live status, then refresh Mission.

R.O.B. does not move from game flashes

Confirm the game is selected and the console is online. Mission should show GAME FRAMES LINKED. If it does not, select lr-robvision-fceumm or lr-robvision-nestopia in RetroPie, or confirm the registered ROM uses its R.O.B. Vision wrapper in Batocera, then restart the game. Check the Activity Feed for decoded or blocked commands.

The blue or red gate stays still

Use an isolated Fast Gate test in live Gyromite. Confirm the console is online and Game A is running. Watch the matching gate while the button is held. Use Release Both when done.

Stack-Up rejects a move

Check R.O.B.'s tray, height, and grip. He cannot pick up empty space, move out of range, or place a carried group where it will not fit. The Activity Feed explains the rejected command.

Demo button is unavailable

Exit the running game first. Demo mode works when the console is paired but idle. Choose Home to reset a sequence.

08 / GOOD TO KNOWFAQ

Common questions

Can I use a phone or iPad?

Yes. Open the UNO Q dashboard address in a browser on the same trusted network. The live state belongs to the UNO Q, so reloading the page does not reset the game.

Why are there R.O.B. Vision versions of FCEUmm and Nestopia?

lr-robvision-fceumm and lr-robvision-nestopia are RetroPie launch choices. Each uses the original emulator through a small wrapper that sends game flashes to R.O.B. Vision. The standard emulator choices play without the automatic frame link. On supported Batocera, the installer selects the R.O.B. Vision FCEUmm wrapper for registered ROMs; Nestopia is available as a per-game choice.

How does R.O.B. read the game?

The console reads the game’s light signals from rendered NES frames and sends complete commands to the UNO Q.

Does the red Test light mean R.O.B. is moving?

No. A blinking red light acknowledges the game’s Test-mode signal; brief steady red acknowledges a ready-light command. Movement needs a separate complete optical command.

Why does a gyro stop spinning?

Each virtual gyro has an illustrative 55-second spin lifetime. When it tips or leaves a pad, that virtual gate releases.

Can R.O.B. see Hector or score Stack-Up?

Use the game screen to check Hector’s position, target stack, score, and victory. The frame link reports movement commands.
