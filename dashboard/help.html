01 / THE BASICS2 MIN READ

Start here

R.O.B. Vision turns game commands into a lively virtual robot. The UNO Q is his controller, your browser is his stage, and RetroPie runs the NES game.

01

Open the live panel

Start R.O.B. Vision in UNO Q App Lab, then visit http://arduiain.local/dashboard/ on your laptop, tablet, or phone. If VirtualGlove is running in App Lab, stop it first.

02

Run a demo

On Mission, choose Gyromite or Stack-Up and select Run Demo Sequence. R.O.B. and the pieces animate without a camera or game. Demo mode is available while RetroPie is paired and idle.

03

Connect the game

On Setup, check the RetroPie link and game controls. Launching a supported game on RetroPie selects its live scene automatically. The game-frame link can move R.O.B. without a camera.

Looking at a local file?A page opened with file:// is only the offline preview. It cannot show the UNO Q camera or current RetroPie game. Use the arduiain.local address for live play.
02 / GET CONNECTEDSETUP

Set up the link and camera

Pair RetroPie

  1. Make sure the R.O.B. Vision receiver and launch hooks are installed on RetroPie.
  2. On RetroPie, run python3 /home/pi/rob-vision/tools/retropie_pair.py.
  3. Enter the displayed console address, six-digit code, and fingerprint on Setup, then choose Pair Console.
  4. Choose Check Link. RETROPIE ONLINE means RetroPie has recently contacted the UNO Q.

Pairing is normally a one-time step. It does not install RetroPie software or controller mappings.

GO TO CONSOLE LINK ↗

Aim the camera

  1. Connect the camera to the UNO Q and point it at the game's flashing screen area.
  2. Choose Start Camera Check and keep the flash area inside the green rectangle.
  3. Read the delivered frame rate and signal level. A requested 60 fps is not a guarantee.
  4. Use the game's Test mode and Watch Test Signal to check the red light.

Reset & Reconnect retries camera capture in software. It does not power-cycle the USB hub.

03 / PLAY A GAMEGYROMITE

Move the red and blue gates

Gyromite has two virtual gyros, holders, a spinner, and two colored pads. A spinning gyro on a pad can keep a gate lowered while R.O.B. moves elsewhere. R.O.B. can also hold an unspun gyro on one pad to operate a single gate.

Fast Gates

During live Gyromite, stop the camera to show Fast Gates. Select Lower Blue or Lower Red for an immediate press; select it again to release. Release Both raises both. Every hold ends automatically after 60 seconds.

Keyboard shortcuts: 2 blue, 1 red, 0 release both. If you moved a gyro with regular controls, choose Home before Fast Gates.

What the game receives

The UNO Q's virtual pad state travels to RetroPie's Controller 2. Both gate colors have been verified in Game A with the current mapping. The game screen remains the way to confirm Hector's position and a gate's actual response.

On game exit, lost link, or stale receiver data, both virtual buttons release.

04 / PLAY A GAMESTACK-UP

Arrange the five blocks

R.O.B. Vision shows five colored blocks and five trays. The current live model starts with all five on Tray 3. Use Left, Right, Up, Down, Open, Close to move R.O.B. one step at a time. When he closes his hands around a lower block, he carries that block and every block above it as a group.

Try a transfer

At the ROBOT BLOCK screen, press Select to open Stack-Up’s mode list; choose Test and press Start. The Test signal appears over the ROBOT BLOCK artwork. On Setup, choose Stack-Up and Watch Test Signal to check R.O.B.’s red light. In Direct mode, jump Hector onto a command key and watch R.O.B. act on Mission. The six manual commands remain available for checks. Watch the Live Model and Game Table. An invalid pickup or placement is rejected without moving any block. Home restores the initial stack.

What is not automatic

The game sends movement commands, not a block color, destination, target pattern, or score. R.O.B. Vision cannot judge the game's result. Stack-Up has no Gyromite-style gate-button return path. All six Stack-Up command types were confirmed through the live RetroPie game-frame link. Longer sessions and Memory/Bingo still need verification.

06 / READ THE PANELSTATUS & SIGNALS

What the indicators mean

Connected

GYROMITE / CONNECTED means this browser can reach the UNO Q controller with Gyromite selected. The RetroPie link is reported separately as RETROPIE ONLINE or RETROPIE OFFLINE on Setup and Mission.

Game Selected

Gyromite or Stack-Up was chosen manually or identified by exact RetroPie ROM filename. It does not mean the camera is aligned.

Camera Capturing

Frames are arriving; Setup shows the measured rate and crop. A visible image alone does not prove a complete command can be decoded.

Test Light

Blinking means Gyromite’s green field or Stack-Up’s alternating green signal was detected. Steady red means a separate ready-light command was decoded. Neither moves R.O.B.

07 / GET UNSTUCKTROUBLESHOOTING

Fix a problem

RetroPie is online, but no game is selected

RetroPie can be online while idle. Launch a registered Gyromite or Stack-Up ROM. If you opened a file:// page, switch to the UNO Q address. Refresh Mission for a current snapshot.

R.O.B. does not move from game flashes

Open Setup and confirm the game is selected and RetroPie is online. During RetroPie play, Mission should show GAME FRAMES LINKED. If it does not, select lr-robvision-fceumm or lr-robvision-nestopia for that game in RetroPie, then restart it. Check Mission’s Activity Feed for decoded or blocked commands. The camera is optional for this game-frame path.

The blue or red gate stays still

Use an isolated Fast Gate test in live Gyromite with camera capture stopped. Confirm RetroPie is online and Game A is actually running. Watch the matching gate while the button is held. Use Release Both when done.

Camera disconnected or frozen

Reconnect the camera cable and choose Reset & Reconnect on Setup. This retries OpenCV capture. If the device is still missing, inspect its power and physical connection.

Stack-Up rejects a move

Check R.O.B.'s tray, height, and grip. He cannot pick up empty space, move out of range, or place a carried group where it will not fit. The Activity Feed explains the rejected command.

Demo button is unavailable

Exit the running game first. Demo mode works when RetroPie is paired but idle. Choose Home to reset a sequence.

08 / GOOD TO KNOWFAQ

Common questions

Do I need a physical R.O.B. or Nintendo accessories?

No. The UNO Q runs R.O.B.'s virtual state, and the browser draws the robot, gyros, spinner, pads, trays, and blocks.

Can I use a phone or iPad?

Yes. Open the UNO Q dashboard address in a browser on the same trusted network. The live state belongs to the UNO Q, so reloading the page does not reset the game.

Why are there R.O.B. Vision versions of FCEUmm and Nestopia?

lr-robvision-fceumm and lr-robvision-nestopia are RetroPie launch choices. Each uses the original emulator through a small wrapper that sends game flashes to R.O.B. Vision. They are not separate emulators. The plain lr-fceumm and lr-nestopia choices play the game but do not provide the automatic frame link. Both R.O.B. Vision choices are installed on this RetroPie; the supported games currently use FCEUmm.

Can I play without a camera?

Yes. With the installed RetroPie game-frame link, Gyromite and Stack-Up can move the virtual R.O.B. without a camera. The camera is still useful for screen alignment and Test-mode checks. Demos and manual controls also work without it.

Does the red Test light mean R.O.B. is moving?

No. A blinking red light acknowledges the game’s Test-mode signal; steady red acknowledges a ready-light command. Movement needs a separate complete optical command.

Why does a gyro stop spinning?

Each virtual gyro has an illustrative 55-second spin lifetime. When it tips or leaves a pad, that virtual gate releases. The time is a game model setting, not a measurement of Nintendo hardware.

Can R.O.B. see Hector or score Stack-Up?

No. The game-frame link reports light commands, not the professor's location, target stack, score, or victory.
