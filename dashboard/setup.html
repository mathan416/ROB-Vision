01 / CONSOLE LINKCHECKING

Connect RetroPie

RetroPie is already paired and its receiver is online. You can continue to the camera check.

On RetroPie, run python3 /home/pi/rob-vision/tools/retropie_pair.py. It displays a six-digit code and a SHA-256 fingerprint for five minutes. Compare both here before pairing.

The receiver must be installed on RetroPie before pairing.

02 / CAMERAOFFLINE

Aim at the game screen

Place the UNO Q camera so the game's optical flash area fills the green rectangle. Try 60 fps or faster with short exposure; use Test mode to confirm that your camera and screen can read the flashes. Higher frame rates give more timing margin.
