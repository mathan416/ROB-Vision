04 / GAME SIGNALWAITING

Game Test light

Open the game's Test mode while its game frames are linked. Gyromite shows sustained green; Stack-Up alternates green and white. R.O.B.'s red light blinks automatically when either signal is recognized. A decoded ready-light command lights it steadily for a moment. The light returns to normal after Test mode ends. Neither signal moves his arms.

In Stack-Up, press Select at the ROBOT BLOCK screen to open the mode list, choose Test, then press Start. The Test signal appears over the ROBOT BLOCK artwork.
